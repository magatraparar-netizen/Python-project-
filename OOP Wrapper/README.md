# OOP Wrapper

## Project Objective

This project demonstrates Object-Oriented Programming concepts in Python using an Employee Management System.

## Concepts Used

- Class and Object
- Inheritance
- Encapsulation
- Method Overriding
- Constructor
- Destructor
- Getter and Setter
- super()
- issubclass()
- Menu Driven Program

## Classes

### Person
Base class with name and age.

### Employee
Inherits Person and contains employee ID and salary.

### Manager
Inherits Employee and adds department.

### Developer
Inherits Employee and adds programming language.

## Menu

1. Create a Person
2. Create an Employee
3. Create a Manager
4. Create a Developer
5. Show Details
6. Exit
