# Fundamental Booster - Personal Data Collector

## Project Description

This is a basic Python project that collects personal information from the user and displays the information in a simple format.

## Information Collected

- Name
- Age
- Height
- Favourite Number

## Concepts Used

- input() and print()
- Variables
- Data Types
- Arithmetic Operators
- Type Casting
- type() function
- id() function

## Features

- Takes user information as input
- Calculates approximate birth year
- Performs basic calculations
- Shows the data type of variables
- Shows the memory address using id()
- Demonstrates type casting

## Technologies Used

- Python

## How to Run

1. Open the project in VS Code.
2. Open the Python file.
3. Run the program.
4. Enter the required information.

## Conclusion

This project helped me understand the basic concepts of Python such as input, output, variables, operators, type casting, type(), and id().
