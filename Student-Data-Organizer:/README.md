# Student Data Organizer

This is a basic Python project.

It stores and manages student information such as name, age, grade, date of birth, and subjects.

It allows users to add, display, update, and delete student records.

It also displays unique subjects offered by all students.

## Concepts Used

* List
* Dictionary
* Set
* Tuple
* While loop
* For loop
* If-else
* Input and output
* f-string
* Type casting
